# 邮箱重置：本地隔离验证记录

日期：2026-11-03。没有操作正式数据库、发送真实邮件、启用真实 Gmail、推送或部署。

## 本轮检查

基于当前顾客后台复制到本地隔离目录，以 Wrangler/workerd、单独的 SQLite Durable Object 数据和虚构凭据启动。仅在隔离副本中用内存模拟发信器和测试收件箱替换 Gmail；测试收件箱不在仓库源码或生产 Worker 中。所有账号均为虚构 `example.invalid`。

- 注册账号、使用已登录会话申请验证、模拟收邮件、确认邮箱成功；验证链接重复使用被拒绝。
- 请求重置、模拟收邮件、使用链接设置新密码；旧会话失效、旧密码登录失败、新密码登录成功，重置链接重复使用被拒绝。
- 验证过的账号修改邮箱后再改回原地址，验证状态仍撤销；未重新验证不能触发重置邮件。
- 单元与路由模拟测试覆盖未验证邮箱、管理员排除、链接过期、变更账号、失败回滚与旧会话撤销；测试不是真实 Gmail 或独立安全审计。
- 两端构建、后台语法与 Wrangler dry-run 已通过。仅是构建及本地功能检查，不是生产部署。

## 仍待完成

- 浏览器真实交互、英文界面、PWA 缓存、Gmail OAuth 授权及邮件送达；外部授权、跨网络/设备及异常路径测试。
- 注册流程目前允许未验证账号登录；需明确用户是否希望注册时强制验证。原有客户须登录后验证邮箱，未验证邮箱不能用来找回密码。
- 真实 Gmail 使用限制、授权续期、失败告警及“已发送”中含重置链接的保护。开发者勿索要用户 Gmail 密码、验证码或密钥。
- 针对账号枚举、邮件盗刷、服务故障、失效链接及客户隐私的安全复核，独立安全审计、健康数据及跨境合规评估。
- 国内阿里云短信认证和手机找回密码尚未实现；备份与恢复演练未完成。不能因本地测试通过而上线。
- `EMAIL_RECOVERY_ENABLED` 默认关闭，生产须在充分测试和用户明确同意后才可考虑启用。任何生产变更先制定备份、回滚及协同部署计划。不得将本地模拟发信器和测试接口部署到正式环境。
