# Cloudflare 部署包本地验证记录

日期：2026-11-01。本记录针对本地 Cloudflare Wrangler/workerd 隔离测试环境和虚构数据，不代表已部署到您的 Cloudflare 账户，也不代表已经通过真实手机、真实域名、真实网络或生产安全/合规验收。

## 测试范围

- Node.js 22、Wrangler 4.156.0：Worker `deploy --dry-run` 打包成功；Pages Functions 本地编译成功。Pages 顾客与管理站通过本地 Service Binding 连接同一个 SQLite Durable Object。
- 20 项浏览器流程：注册、长期安全会话、预约、病情图文、健康打卡、联系人、资料、管理登录、分诊、管理员查看图片、提醒创建、CSV 导出、匿名及跨站请求权限检查、两个 PWA 清单与图标。
- 中英文与十个穴位、两端无通用试用横幅、公开图片；Chromium 的 Android 模拟布局及单独的 WebKit iPhone 模拟布局。均不是实际手机实测。
- 两个不同测试主机名：各自登录、共用数据、管理员回复顾客；超过 2 MB 的虚构 PNG 分成多条加密记录，顾客与管理端读回内容一致，删除后检查分块级联清理。
- 身份档案加密、号码脱敏、图片类别/文件名/确认检查、消息图片；测试验证码限制虚构身份；顾客和管理本机加密离线档案、断网打开及手动导出 ZIP。
- 后台重启后虚构账号与会话保留；错误加密密钥导致 503，恢复原密钥后数据仍可访问。
- 未配 Web Push 密钥时，推送接口明确返回 503；配置临时测试密钥时，模拟 Service Worker 推送事件可创建通知，内部地址订阅被拒绝。用不存在的 Mozilla 测试订阅触发推送服务拒绝并删除该订阅；观察到 Durable Object Alarm 到期执行。**没有真实订阅、真实手机送达或后台可用性验证**。
- 后台、前端 npm audit 在验证时无已知依赖漏洞；这不等于代码通过安全审计，也不能保证未来无漏洞。

## 已知限制

- 图片仅检测文件头和尺寸，不等于完整解码或证件照片识别。单张上限 4 MiB。
- 一个 SQLite Durable Object 存储共享数据，存在账户和对象容量、吞吐及计费限制。未建立完整备份恢复流程。
- 演示账号和模拟认证仅适合虚构数据；短信、邮件、微信、Google、Apple 等真实认证没有接入。
- 已包含完整项目源码和静态资源，但尚未进入用户 Cloudflare 账户进行部署，也没有产生持久的公网网址。
